# 안녕하세요, 이우영입니다.

복잡한 문제를 구조화하고, 실제로 동작하는 소프트웨어로 구현하는 과정에 관심이 많은 소프트웨어 엔지니어입니다.
현재는 **백엔드 개발과 데이터 처리 시스템**을 중심으로 공부하고 있으며, SICP를 통해 프로그래밍의 계산 모델과 추상화에 대해서도 함께 학습하고 있습니다.

<br>

## 주요 프로젝트

### [MarketLens](https://github.com/ggj0228/marketlens-be) · [Frontend](https://github.com/ggj0228/marketlens-fe)

**주식 뉴스 수집·분석 및 개인화 정보 제공 서비스**

* `수집 → 파싱 → 분석 → 집계 → 제공` 형태의 뉴스 데이터 파이프라인 설계
* Task 기반 처리 구조와 실패 작업 재처리 및 복구 기능 구현
* Cursor 기반 페이지네이션을 통한 뉴스 중복·누락 최소화
* Redis 기반 인증 및 Telegram 계정 연동
* 외부 뉴스 API와 AI 분석 API 연계

`Java` `Spring Boot` `MySQL` `Redis` `Docker` `React`

<br>

### [MKX](https://github.com/ggj0228/mkx-be)

**증권사·기업·투자자를 연결하는 통합 증권 거래 플랫폼**
한화시스템 BEYOND SW Camp 16기 최종 프로젝트 **1위**

**담당 영역 — Identity & Admin / News & Disclosure**

* 사용자 인증·인가 및 역할 기반 권한 관리
* 사용자 및 관리자 도메인 구현
* 관리자 기능 및 계정 관리
* RSS 기반 외부 뉴스 수집 및 종목 뉴스 연동
* 기업 공시 등록·수정·정정 및 승인·반려 기능 구현

`Java` `Spring Boot` `MySQL` `Redis` `Kafka`

<br>

### [SICP Study](https://github.com/ggj0228/sicp-learn)

*Structure and Interpretation of Computer Programs*를 Scheme/Racket으로 공부하며 정리하고 있습니다.

단순히 문법을 익히는 것이 아니라, **프로그램이 어떤 계산 과정을 만들고 이를 어떻게 추상화할 수 있는지 이해하는 것**을 목표로 합니다.

**현재까지 학습한 내용**

`Recursive / Iterative Process` · `Order of Growth` · `Higher-Order Procedures` · `accumulate` · `Fixed Point` · `Average Damping` · `Newton's Method` · `Continued Fraction` · `Data Abstraction`
